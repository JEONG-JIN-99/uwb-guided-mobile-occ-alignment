# 1m 정적 정렬 및 빨간색 인식 실험 분석

## 1. 문서 목적

이 문서는 1m 거리에서 중앙 60% 크롭과 완화된 빨간색 인식 조건으로
수행한 다음 세 실험을 비교한다.

1. 정렬 전 빨간색 인식 사전검사
2. 정렬 명령 직후 안정화 없이 0.2초 동안 인식한 정적 정렬
3. 정렬 명령 후 0.5초 안정화하고 0.2초 동안 인식한 정적 정렬

분석의 핵심 질문은 다음과 같다.

- 정지 상태에서 빨간 표식을 안정적으로 인식하는가?
- 안정화가 없을 때와 0.5초 안정화했을 때 인식률은 얼마나 달라지는가?
- 초기각과 짐벌 이동량에 따른 인식률 경향이 안정화 후에도 남는가?
- 성공 프레임의 빨간색 픽셀 분포가 안정화 후 사전검사 수준으로 회복되는가?

## 2. 분석 대상

| 구분 | 결과 경로 | 표본 수 |
|---|---|---:|
| 빨간색 사전검사 | `result/red_detection_precheck/run_20260727_221312_distance_1m_crop_0.6/` | 100 |
| 안정화 없음 | `result/static_alignment/run_20260727_220119/` | 100 |
| 0.5초 안정화 | `result/static_alignment_after_settle/run_20260727_220727/` | 100 |

분석에는 각 폴더의 CSV만 사용했으며 실패 프레임 이미지는 확인하지 않았다.

## 3. 공통 실험 조건

세 CSV에 기록된 공통 영상 및 색상 조건은 다음과 같다.

| 항목 | 값 |
|---|---:|
| 거리 | 1m |
| 크롭 비율 | 0.6 |
| 빨간색 검사 시간 | 0.2초 |
| 대상 색상 | red |
| Hue 범위 | 0–7 또는 173–180 |
| Saturation 하한 | 130 |
| Value 하한 | 110 |
| 전체 빨간 마스크 최소 면적 | 125px |
| 최대 연결 빨간 영역 최소 면적 | 50px |

두 정렬 실험의 초기각 순서는 100회 모두 같고 관측 범위는 -50°~49°다.
두 실행 모두 서보 명령 제한은 한 번도 발생하지 않았다.

다만 정렬 실험은 서로 별도로 실행했으므로 UWB 측정값과 카메라 프레임
시점은 같지 않다. 동일 초기각 분포의 반복 실험으로 비교할 수는 있지만,
동일 영상을 사용한 완전히 통제된 A/B 판정으로 해석해서는 안 된다.

## 4. 전체 빨간색 인식률 비교

| 실험 | 성공 | 색상 미검출 | 카메라 타임아웃 | 전체 성공률 | 프레임 가용률 | 프레임 조건부 인식률 |
|---|---:|---:|---:|---:|---:|---:|
| 사전검사 | 100 | 0 | 0 | 100% | 100% | 100% |
| 안정화 없음 | 65 | 32 | 3 | 65% | 97% | 67.0% |
| 0.5초 안정화 | 100 | 0 | 0 | 100% | 100% | 100% |

프레임 조건부 인식률은 카메라 타임아웃을 제외하고 실제 새 프레임을 받은
회차만 분모로 사용한다.

```text
사전검사           = 100 / 100 = 100%
안정화 없음        = 65 / 97 ≈ 67.0%
0.5초 안정화       = 100 / 100 = 100%
```

안정화 없음과 비교하면 0.5초 안정화의 전체 성공률은 65%에서 100%로
`35%p` 증가했다. 프레임 조건부 인식률은 67.0%에서 100%로 `33.0%p`
증가했고, 색상 미검출 32회와 카메라 타임아웃 3회가 모두 사라졌다.

사전검사와 0.5초 안정화 실험이 각각 100/100 성공했으므로, 현재 조건에서
정지한 빨간 표식의 인식 성능은 충분하다.

## 5. 빨간색 사전검사

### 5.1 전체 결과

100회 모두 성공했다.

```text
전체 성공률 = 100 / 100 = 100%
카메라 프레임 가용률 = 100 / 100 = 100%
프레임 조건부 빨간색 인식률 = 100 / 100 = 100%
```

색상 미검출과 카메라 프레임 타임아웃은 모두 0회다.

## 6. 안정화 없는 정적 정렬

### 6.1 전체 결과

`pre_recognition_settle_time_s=0`이므로 정렬 명령 직후 0.2초 검사를
시작한다. 이 결과는 정지 완료 후의 순수 색상 인식률이 아니라
**짐벌 이동 중 0.2초 안에 표식을 인식한 비율**이다.

| 상태 | 횟수 | 전체 대비 |
|---|---:|---:|
| `success` | 65 | 65% |
| `color_not_detected` | 32 | 32% |
| `camera_frame_timeout` | 3 | 3% |

카메라 타임아웃은 6, 35, 46회차에서 발생했다. 100회 모두
`servo_clipped=0`이므로 서보 명령 범위 제한은 실패 원인이 아니다.

### 6.7 UWB 측정과 최종각 참고

초기각과 UWB raw 방위각의 단순 선형 관계는 다음과 같다.

```text
uwb_raw_azimuth_deg ≈ 0.898 × initial_gimbal_ros_deg + 3.039°
```

UWB 값을 적용한 최종 계산각은 평균 -3.19°, 범위 -12.0°~2.9°로 음의
방향에 치우쳤다. 최종 정렬에는 체계적인 잔여 오차가 있지만, 무안정화
인식 성공 여부는 절대 최종각보다 이동량과 더 강하게 연결됐다.

빨간색 인식 성공은 표식이 시야에 들어왔다는 뜻이지 카메라 광축과 표식
중심이 정확히 일치했다는 뜻은 아니다. 정렬 정확도는 인식률과 별도의
오차 지표로 평가해야 한다.

회복됐다는 해석을 뒷받침한다.

## 9. 결론

현재 1m, 중앙 60% 크롭, `S≥130`, `V≥110`, 전체 면적 125px, 연결 영역
50px 조건의 결과는 다음과 같이 정리된다.

1. 정렬 전 사전검사는 100회 모두 성공했다.
2. 안정화가 없으면 전체 성공률은 65%, 프레임 조건부 인식률은 67.0%다.
3. 무안정화에서는 이동량 30° 미만일 때 프레임 수신 시 모두 성공했지만,
   30°~40°는 5.3%, 40° 이상은 0%였다.
4. 0.5초 안정화 후에는 색상 미검출과 카메라 타임아웃 없이 100회 모두
   성공했다.
5. 안정화 후에는 모든 초기각 및 이동량 구간에서 인식률이 100%로,
   각도에 따른 인식률 저하가 완전히 사라졌다.
6. 안정화 후 빨간색 픽셀 수와 화면 중심거리는 사전검사 수준에 가깝게
   회복됐다.

따라서 1m에서도 무안정화 실패는 정지 상태의 색상 인식 조건보다 이동 중
영상의 영향을 받았다는 결론이 강하게 뒷받침된다. 정적 정렬에는 0.5초
안정화를 유지하는 것이 적절하며, 현재 빨간색 인식 임계값을 더 낮출
근거는 없다.

다만 현재 분석은 빨간 표식이 있는 양성 조건만 다룬다. `125px/50px`와
`S≥130`이 배경의 다른 물체를 빨간 표식으로 오인하지 않는지 확인하려면
빨간 표식이 없는 음성 대조군도 별도로 측정해야 한다.
