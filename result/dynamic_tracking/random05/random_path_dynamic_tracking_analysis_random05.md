- 회색 음영은 이상적 요구각이 짐벌 가동 범위를 벗어나 MAE에서 제외한 시간이다.
- 시간축은 범위 초과 시간을 제거하지 않은 실제 로버 경과시간이다.
- 정렬 방향은 엔코더 실측이 아니라 실제 적용된 짐벌 명령 기반 방향이다.
